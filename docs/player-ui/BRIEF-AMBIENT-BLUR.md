## 一、复现与根因（已定位，直接采信）

用罐头那首「風と行く道」的真实封面（`https://p2.music.126.net/q6Tnn3_rMnFu1cZesyrCEg==/109951173538461458.jpg`）复现，
尺寸 462×511（他截图的档）：

**我们的背景** = `.stage-ambient` 画一条 **12 段竖向渐变**（`--ambient-gradient`，由 JS 在封面右缘
72~92% 宽取 12 段、每段水平平均得到色标拼成）。实测该封面右缘 12 段的相对亮度：

```
段0-6   lum 0.58 .. 0.50   （浅：天/雾）
段7     lum 0.17           ← 断崖
段8-10  lum 0.11 .. 0.08   （暗：山/草）
段11    lum 0.03           ← 近黑  ← 罐头看到的「右下黑块」
```

段与段之间**没有过渡**，浅段直接掉到近黑段，于是右侧落下一块 `lum≈0.03` 的**平色**（无任何细节），
这就是「生硬黑块」。横剖证实：x 从 0.55w 到 0.97w 全段同值 —— 它是渐变，不是图。

**网易的背景** = **封面本身模糊放大铺满**（罐头参考图里能看到模糊的人、草地、晚霞，有结构、有连续过渡，
根本不存在「段」）。

## 二、要做的

**把主背景从「采样渐变」换成「封面模糊放大铺底」**（网易同款）：

1. **底图** = 当前封面（同一张）模糊放大，铺满整个舞台到最右缘。这就是现成的 `.cover-haze`
   （模糊副本）—— 现在它被降级成「取色失败时的兜底」，`.player.ambient-ok .cover-haze { display:none }`。
   **改为常驻**：有封面就显示（取色成功与否都显示），无封面才退回纸面兜底。
2. **采样取色保留，但只用来定字色深浅（极性）**，不再拿它画背景。即：
   `probeAmbient` 的色标仍算，用于算 WCAG 对比度择优 `data-ambient="light|dark"`；
   但 **`--ambient-gradient` 不再需要**（可保留变量名给兜底，或干脆去掉渐变那条路）。
   取色失败（非 CORS / 解码失败）→ 极性退回主题极性即可，**背景不受影响**（底图是 CSS background，不吃 CORS）。
3. **模糊/缩放/蒙层**照网易手感调：模糊要够（约 40~56px）、放大把模糊边缘推出画面（scale ~1.2~1.3）、
   饱和可略提。**不要再叠把颜色洗没的厚纸色蒙层**（现在 `.cover-haze::after` 那层 58%/38%/62% 的纸色
   就是「洗白」元凶之一）—— 只保留**保字可读的最小蒙层**，且只压在歌词列那侧（左列封面区不要蒙）。
   目标：底图有结构、有颜色，但歌词字仍可读（这条是硬线，见第四节）。

## 三、为什么这样更好

- **不再有硬色块**：模糊图是连续场，没有「段」。
- **更简单更稳**：CSS `background-image` 永远能用，**不吃 CORS**；取色失败也不影响背景观感。
- 与罐头要的「整块播放区跟着封面颜色」完全一致 —— 而且是真的「封面颜色」，不是采样近似。

## 四、边界与硬线

- **可读性 > 还原度**：换完必须验深色封面 + 浅色封面两种，歌词在中部区域对比度够（沿用现有闸门：
  中部 ≥ 4.5、最差段 ≥ 3.0）。两种极性（浅纱墨字 / 深纱纸字）都要成立。
- **无封面**：`.nocover` 仍走纸面 `--cover-fallback`，底图不出现。取色失败也优雅退回，不白屏不刷错。
- 层序保持：底图（z0）→ 封面本体（z1，贴左满高/宽窗 contain）→ 歌词列蒙层（z2）→ 标题块（z3）。
- 保留所有 `id`/`data-*`；两个 html 同步（只差 `<body data-shell>`）；单文件无构建；ES5。
- 别动歌单模型 / 导入 / 生命周期 / 鉴权层。
