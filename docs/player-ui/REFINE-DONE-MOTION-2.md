## 二、B3 的坑与解法（重点）

**根因**：`createMediaElementSource` 只对**同源**（或 CORS 干净）的媒体有效。
而 `music/go` 是 302 跳到网易云 CDN，该 CDN **实测不回 `access-control-allow-origin`**。
后果：设 `crossOrigin` → 加载失败；不设而硬接 → **输出静音**，且**不可逆**
（先播本地曲挂上图，之后在线曲全哑）。

**解法**：`music/go` 从「302 跳转」改成「服务端分片流式代理」，媒体变同源：

- 每个 Range 片压到 **2 MiB**（清单 `network.maxResponseBytes` = 5 MiB，是响应体硬上限）；
- 靠 `Content-Range` + `Accept-Ranges: bytes` 让浏览器续片（拖动进度条也靠它）；
- CDN 地址缓存 5 分钟，过期/失败重解析一次；
- 只代理真回 `Content-Range` 的响应；否则**退回 302**，至少保住播放。
