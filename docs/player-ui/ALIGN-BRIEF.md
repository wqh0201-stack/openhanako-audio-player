## 1. 功能范围（罐头已拍板，别扩也别砍）

保留：播放列表、播放模式、播放进度条、歌词显隐（隐藏时只剩封面，渐变蒙层消失）、
记忆（上次曲目/进度/音量/模式）、本地 + 在线导入。

**去掉（已在现版去掉，别加回来）**：PV、切主题（齿轮）、标准/唱盘模式、
队列页的 列表/搜索/场景/编排 tabs、全部/本地/在线/收藏 筛选、收藏 ♡、实例编号、字号按钮。
所以设计稿里的「标准 / PV / 歌词」tab 行**不能原样搬**——它去掉 PV/标准后只剩「歌词」一项，没有意义。

## 2. 当前生产 UI（要对齐的对象）

- `ui/index.html` / `ui/standalone.html`（薄壳，只差 `<body data-shell="card|window">`）
- `ui/style.css`、`ui/app.js`（逻辑已接线完成，**别改逻辑**，只动视觉/DOM 呈现）
- 布局三态由容器尺寸决定：`data-layout="long|compact|wide"`（`app.js` 的 `applyLayout`）
- 主题只消费宿主注入的 CSS 变量（`--bg/--bg-card/--text/--accent/--border/--text-muted/--text-light`）。
  **宿主没有 `--surface`**，已从 `--bg-card` 派生；不要新增同名宿主变量覆盖。

## 3. 差距清单（我初判，画师自己再核一遍并补全）

对着设计稿逐项核，尤其是：

1. **顶栏信息**：设计稿是「歌名（大、直接压在封面左上）+ 歌手」，**没有底框**；
   现版是一个半透明深色圆角小盒（`.info-card`）包着歌名+歌手。→ 对齐：去掉盒子，
   用**顶部渐变蒙层**保证可读；歌名字号对齐设计稿（更大、更立得住）。
2. **底部控制条**：设计稿是 `⟳ ⏮ (⏸) ⏭ 🔊 | ☰ 队列 48`，播放键是实心强调色圆钮；
   现版在最左多了一个「歌词」药丸按钮。→ 「歌词」按钮**保留**（tab 行去掉后它没别处可放），
   但要让它读起来像控制条的一部分，不是外挂的第三样东西；核对播放键/图标/间距/分隔符与设计稿。
3. **封面**：设计稿是真实封面全出血、渐隐融入。现版无 `pic` 时是兜底渐变。
   → 兜底别是"糊掉的彩色渐变"，做一个更安静、像设计稿留白的兜底（可用主题色 + 极淡纹理）。
   **不要**把效果图里的山景硬编码成所有曲目封面。
4. **歌词区**：当前句更大更亮、前后句减弱；核对字号阶梯、行距、居中留白是否够"呼吸"。
5. **队列行**：设计稿每行是「封面缩略 + 歌名 + 歌手 + 时长 + ⋯」，正在播放那行有节奏指示。
   核对手指大小、行高、缩略圆角、分隔感、当前行高亮（强调色）。
6. **队列头**：设计稿是「播放队列 48 首」+ 右上 `＋`。现版一致，核对排版与留白。
7. **矮卡分页**：设计稿播放页 / 队列页切换，队列页左上「‹ 返回播放」。核对该返回入口与整页高度分配。
8. **独立窗口**：设计稿是左侧封面 + 歌词、右侧抽屉队列、底部控制贯穿（左侧带曲目信息）。
   核对抽屉宽度（约 320–380）、圆角、阴影、与底栏的边界关系。
9. **圆角 / 间距 / 字号 / 图标**：内部控件约 5px 圆角；根容器直角、无外描边/外阴影；
   只用 SVG 线描图标（禁 emoji）；正文 13–14px、次级 11–12px、歌名 18–22px、当前歌词 20–26px、**最小 11px**。

## 4. 硬约束（踩了必炸）

- 不动 `app.js` 的业务逻辑；**保留 app.js 依赖的所有 `id` 与 `data-*` 钩子**
  （`frame player sceneTop queue queueHead queueList lyrics lyricWrap lyricScrim lyricBack drawerScrim seek vol toast audio`、
  `playBtn prevBtn nextBtn modeBtn muteBtn lyricToggle queueBtn backBtn drawerCloseBtn importBtn removeBtn morePop importPop importNote linkInput linkAddBtn report`）。
  要加元素可以，别删/改名现有钩子。
- 改 `ui/index.html` 必须同步 `ui/standalone.html`（只允许 `<body data-shell>` 一行差异）。
- 单文件、无构建、无框架、无 CDN。
- 聊天卡片右上角 **100×40 CSS px** 是宿主控件安全区，别放文字/控件；不用 `position:fixed`；
  最外层保持直角、不加外圆角/外描边/外阴影；禁 emoji；字号 ≥ 11px；颜色走宿主变量。
- 不碰 `lib/`、`manifest.json`、`app-data/`。**不要部署、不要 reload 安装目录**（主代理做）。
