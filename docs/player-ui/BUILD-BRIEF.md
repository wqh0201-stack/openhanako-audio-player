# 极简播放器 · 原型构建简报

你接到的是一个**独立可交互 UI 原型**的构建任务。你没有任何前置上下文，这份简报是自包含的。

## 0. 一句话
在一个目录里做一个**单页、可交互、用演示数据**的极简音乐播放器界面，浏览器直接打开就能点。它是"先看界面、验收后再接线"的预览稿。

## 1. 红线（先看，别越界）
- **只做 `docs/player-ui/` 里的原型。** 不碰生产 `ui/index.html`、不碰后端 `index.js`/`lib/`、不碰 `app-data/`。
- **不接真实音频、宿主、持久存储。** 播放用定时器模拟，数据写死在文件里。
- **不引入构建工具、框架、CDN。** 纯 HTML + CSS + 原生 JS。
- 演示封面用 `docs/player-ui/assets/demo-cover.png`（相对路径引用；加载不到就用渐变兜底，别留白块）。

## 3. 交付
`docs/player-ui/index.html`（可拆 `style.css` / `app.js`，同目录）。
浏览器打开即可交互；页面里要有一个**只在预览存在的开发工具条**（尺寸切换 + 深浅切换），生产接线时整段删掉。

## 4. 功能范围（只做这些，多一个都不要）
**留：**
- 播放/暂停、上一首/下一首、进度条（可点击/拖动 seek）、音量（可拖）+ 静音
- 播放模式：列表循环 / 单曲循环 / 随机 —— **一个按钮循环切**，hover 提示 + `aria-label` 说明当前值
- 歌词显示/隐藏。**隐藏时只留封面图，为文字准备的那层渐变遮罩一起消失**；曲目信息与播放控制各自用局部底色保证可读，不要重新盖满整张图。歌词开启时自动跟随只滚自己的容器；用户手动滚动立即暂停跟随并出现「回到当前歌词」按钮
- 播放列表：**只有「本地」「在线导入」两类曲目，扁平一个列表**。每行：封面、歌名、歌手、时长；移除放在行尾「更多」菜单里。**不加来源筛选行、自建分组、收藏、推荐、电台、场景、编排**
- 导入入口：一个 `＋`，弹出一个小面板（本地文件 / 文件夹 / 在线链接）——原型里点击只做演示（加一条假曲目或弹提示即可）
- 记忆：记住列表、当前曲目、进度、音量、模式、歌词开关、上次是否在播。原型里用内存模拟（页面刷新丢失可接受），**不要写 localStorage**

**砍（一个入口都不留）：** PV、唱盘/黑胶模式切换、主题选择器、字号按钮、实例编号、任何没有明确用途的按钮。

## 5. 视觉 token（用 CSS 变量，浅深两套）
浅色：`--bg #F8F4ED`（纸）· `--surface #FFFDF7`（卡面）· `--text #2A2622`（墨）· `--muted #6B6158` · `--faint #9A9186` · `--accent #537D96`（远山蓝）
深色：`--bg #34424B`（深板岩）· `--surface #414D56` · `--text #E1EAF0` · `--muted #9FB1BC` · `--faint #7C8A95` · `--accent #C99AAF`（藕荷粉）
- 强调色**只用在**：当前曲目、播放键、进度/音量已填充段、激活态。不是到处刷。
- 封面上的歌词用「封面 + 深色渐变蒙层」保证可读；当前行最清晰（加粗放大），前后行淡出。
- 小圆角（约 5–10px）；**根容器直角、无外描边、无外阴影**；**只用 SVG 线描图标，禁 emoji**；所有字号 ≥ 11px。

## 6. 三种布局（按**容器尺寸**切，不看视口）
在 `.frame`（模拟宿主容器）上挂 `ResizeObserver`，给播放器根节点加类：
- **矮卡**（高 < 约 560px）：播放页 ⇄ 队列页 两页互切；底部播放控制常驻；队列页左上角有明确「返回播放」。
- **长卡**（默认）：上方舞台（封面 + 歌词）约 55–60%，下方常驻队列约 40–45%，最底部播放控制。**歌词与队列各自滚动，滚谁都不动顶栏和控制条。**
- **宽窗**（宽 ≥ 约 720px）：舞台在左（封面 + 歌词阅读列），底部控制横贯整宽；队列从右侧作为**舞台内部浮层**打开，只盖舞台、不压缩舞台、不遮底部控制；有关闭按钮，点遮罩外或 Esc 也能关。
- 每块区域**只有一个滚动容器**；顶栏在容器里永远可见；任何状态下**不出现整页双滚动条、不横向溢出**。

## 7. 演示数据
写死一份像样的播放列表（约 10–12 首，中文歌名/歌手/时长，封面统一用 demo-cover），外加当前曲的一整段歌词（约 20–30 行，有重复副歌更好）。别用 lorem ipsum，别用"测试 1/2/3"。
