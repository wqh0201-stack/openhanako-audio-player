# 前端重构实施方案

- 把布局重新收敛到一个容器尺寸驱动的 flex 高度链：固定顶栏与播放控制、可伸缩播放舞台、独立队列区；窄/矮容器使用队列整页切换，独立窗口使用覆盖抽屉。
- 歌词跟随只写 `.lyric-body.scrollTop`，响应用户滚轮/触摸/键盘后暂停跟随，并提供回到当前行；歌词行高亮不调用 `scrollIntoView`。队列滚动位置由列表使用者持有，`renderPL()` 只保存/恢复，不根据播放曲目抢滚动。
- PV 三个歌词定位入口改为只滚动其所属歌词轨道；保留生成的 PV CSS/JS 块原文。`pv/` 源目录不在当前仓库检出，因此不重建 PV。
- 移除应用自有颜色面板、主题变量覆盖、字号 `body.zoom`、旧布局补丁和 popup DOM 注入；主题消费宿主变量，封面由当前曲目图片生成融合背景，音频反应保留并移入设置对话框。
- 播放、在线搜索/导入、歌词缓存与离线库、横幅、收藏、分组、音频反应及后端路由保持现有接线；增加切歌请求代际检查，防止旧歌词响应覆盖新曲。
- 同步 `ui/index.html` 与 `ui/standalone.html`（只保留约定的五行 AudioContext 调试差异），运行 `tools/bump-build.mjs`，以实际生产 HTML 做固定尺寸模拟、动态交互回归和官方静态校验。真实 Hana 宿主交由独立内部验收。
